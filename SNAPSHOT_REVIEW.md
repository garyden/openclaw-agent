# Snapshot review

This export was built from an explicit 58-file allowlist of the current working
copy, including all uncommitted MVP 3.1 source/tests and voice diagnostics. Four
review/configuration files were generated, for 62 exported files in total.
SNAPSHOT_MANIFEST.json lists every file and exported content hash (except itself).

## Included and sanitized

- Current bilingual CRM, follow-up queries, draft-only email generation, synthetic
  diagnostics, safe tests, requirements, public feature docs, and blank XLSX template.
- Generic agent profile example only; real agent configuration was not opened/copied.
- Removed the personalized default user name; generalized personal fixture names,
  local paths, operator setup notes, and spreadsheet author metadata in this export.
- Preserved synthetic matching/ambiguity relationships and test expectations.
- Trimmed trailing whitespace in copied text files; original files were untouched.

## Omitted

Original Git metadata/history, production .env/XML, private configuration, legacy
bot_origin.py, archives, private worklogs/backups, swap files, local logs, market
CSV/raw caches, virtual environments, generated bytecode, and unrelated deleted
startup documents were not copied. The original repository remains the private
record of history and uncommitted work; no deletion/restoration was performed there.

## Validation

The full safe suite passed: 216 tests, using the already installed Python 3.13
ARM64 dependency environment, with execution rooted in this export. No dependency
installation, live API call, Telegram polling, email delivery, Git initialization,
staging, commit, or remote configuration was performed.

Source/privacy checks found no credential-shaped values, known private account
markers/paths, non-placeholder contact addresses, forbidden file types, real XML
stores, or Git directories in the exported snapshot. Synthetic example contacts
and privacy-test strings intentionally remain. The Clients sheet of the exported
workbook contains zero populated rows beyond the header. This is a bounded source
scan, not proof of credential revocation or semantic identification of every name.

All exported text files passed standalone git diff --no-index --check checks.
The original source hashes, Git index, refs, status, and pre-existing deletions
were verified unchanged before export transfer. A human should review the
allowlist, generic configuration, dependency pins, and functional limitations.

## Data-isolation limitation

Enforced development/testing/production data-root selection is NOT implemented.
Default storage is checkout-local memory/memory.xml; manual operations in the
same checkout can share it. Only the safe automated tests use temporary XML and
block network/production-store access. Do not copy production stores or symlink
them into development. See README.md before any live deployment.
